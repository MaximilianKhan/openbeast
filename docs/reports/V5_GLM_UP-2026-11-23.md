### 3.3 Integrity

`evals/audit/integrity_scan.py` on the Mac, 2026-11-23, against the arm
tree's transcripts. The file records its end (`saved`) and was written in
the Mac's zone, so no `--tz` or `--until` was needed.

- **First pass (the scanner at `ea45b9fb`): 1 contaminated,
  176_intermittent_500s_a (a pass).** The hit was two `bash` calls that
  checksummed the fixture's own `tests/` directory under `/tmp`, which the
  task names, from a subshell (`cd /tmp/eval_... && (cd tests && ...)`).
  The scanner treated the bare relative `cd tests` as a `cd` out of
  `/tmp`, so the relative `tests` read as the checkout's `tests/`.
- **The fix:** only an absolute target outside the temp roots, or a
  home-relative one, leaves `/tmp`; a bare relative name descends from
  where the shell is. Tested in `tests/test_eval_integrity_g24.py`. Over
  every transcript on the Mac (1,196), the old and fixed scanners differ
  on this one transcript only.
- **Second pass: 0 contaminated, no hits of any kind** (71 transcripts,
  71 units). The arm hides the web tools, and the Mac's agent shell has
  the network deny, so there were no attempts either. No exclusion.

  eras, at 16K). Both agree in sign; neither isolates a switch.
- **The 16K cap looks like GLM's cost too, unmeasured.** GLM-UP's 16
  wall-hit units all had 2 to 4 capped thinking turns, and 13 ended
  after 10 turns or fewer; DeepSeek's UP wall hits ran 10 to 27 turns,
  and its cap-alone pairs gained +3 to +4. On GLM that is a reading, not a
  measurement: GLM has never run an 8,192-token arm.

### 6.3 Mechanics

- **The forced-act turn worked on GLM:** 22 forced turns in 20 units,
  all 22 ended in a tool call (`force_act_result`, `finish_reason:
  tool_calls`), as on DeepSeek's U (24 of 24).
- **The wall.** 16 wall hits (1 passed), against GLM-C's 20 (4 passed)
  and DS-UP's 11 (2 passed). Unit-hours were level with C (33.7 against
  34.3).

## 7. Caveats

- **Single seed.** One run per arm; the suite's measured noise is about
  ±1 unit (DeepSeek T against T_s1).
- **Crosses harness versions.** GLM-C is era 8eaa5e5f (2026-11-16), GLM-UP
  9bcd5aa6. Between them the harness gained the review 1118 sandbox, the
  eval fetch guard, partial stats and the harness10 switches.
- **Bundled.** C → UP changes the assists, the forced act,
  done-when-verified, the hidden web tools and the planning lines
  together.
- **The harness was tuned on DeepSeek.** UP is a DeepSeek arm run
  unchanged on GLM. A harness change observed on one model does not
  establish a result on another, and this control measures the bundle on
  GLM, not each switch.
- **A model-and-weights comparison with DeepSeek.** GLM runs Mia's 4 bpw
  abliterated EXL3 on TensorFold v0.6.0 (recipe v1.8); DeepSeek runs Mia's
  2.9 bpw stock EXL3 on its own TensorFold recipe.
- **The scanner changed during this review** (§3.3), in the direction of
  fewer flags; the change is tested and moves no other verdict on the Mac.
