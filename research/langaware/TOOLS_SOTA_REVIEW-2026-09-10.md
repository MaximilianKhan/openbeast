# OpenBeast Tool Suite — SOTA Review (2026-09-10)

*9-agent parallel review (4 code reviewers, 4 SOTA researchers, 1 synthesis; 72 raw findings).*

## Top 10 (ranked by impact-per-effort, mixed improvements + new tools)

1. **bash result fidelity bundle** (high / hours) — three compounding bugs in one code path: (a) `_drain()` keeps only the first 4MB and `bash()` slices `output[:50_000]`, so tail-resident failures (pytest summaries, final compiler errors) are discarded and the truncation marker itself is cut off past 50KB (tools.py:119-126, 157-158, 253); (b) nonzero exit codes are invisible whenever the command prints anything (tools.py:251-253); (c) timeouts throw away all partial output — the model can't see which test hung (tools.py:130-134, 254-255). Fix: head+tail capture with visible elision marker, always append `(exit code N)` on rc≠0, attach `kept` buffer to TimeoutExpired. SOTA backing: Claude Code keeps head AND tail; SWE-agent (arXiv:2405.15793) showed capped-with-guidance output was a measurable ACI win.
2. **grep hardening + ergonomics bundle** (high / hours) — (a) *verified live*: a leading-dash pattern is parsed as a grep option — `-v` flipped invert-match and recursed the whole cwd including llama.cpp/.git (tools.py:543-545); fix with `-e {pattern} -- {path}` + `-H`; (b) no `-I`/`--exclude-dir`, so .git trees and build dirs are scanned until an uninstructive 30s timeout — prefer ripgrep 15.2.0 (already installed, gitignore-aware, 10-50x faster); (c) add `context_lines` (-C), `ignore_case` (-i), `max_results` — each absence costs a full round-trip at ~140 tok/s; (d) ERE dialect trap: `\d` and lookaheads silently return wrong/zero matches (verified on GNU grep 3.12) — document the dialect, detect PCRE-isms on zero matches; (e) route path through `_resolve()` (tilde never expands today); (f) fix silent `[:50_000]` slice that also destroys run_reaped's truncation note (tools.py:549 vs 156-158).
3. **read_file context-bomb cap** (high / hours) — file capped at 64MB but the *returned string* is uncapped; one minified line returns megabytes appended verbatim to messages (tools.py:328-336; runner.py:376-380), evicting a 27B's working context. Clamp lines at ~2000 chars, cap total at ~50K, and emit a resumable hint (`use offset=N limit=M`).
4. **Zig `has_main` substring fix** (high / hours) — `"fn main" in src` false-positives on `fn mainLoop`/comments, selecting `zig build-exe` and fabricating "no member named main" errors on clean library code (tools.py:411-417). This directly corrupts the on-arm of the diagnostics A/B — THE ZIG FIX experiment in the standing queue — and can sink its ship rule. Fix: `re.search(r'\bpub\s+fn\s+main\s*\(', src)` + a unit test.
5. **Runner error teaching** (high / hours) — malformed tool-call JSON silently becomes `{}`, producing a misleading "missing argument" error that teaches the model to fix the wrong thing (runner.py:347-349) — the #1 local-model tool-call failure mode; return the parse error + first 300 chars of raw arguments. Unknown-tool errors should list the registry (runner.py:353). Backed by ToolScan's error taxonomy and AgentDebug (arXiv:2509.25370: root-cause-specific feedback → up to 26% relative recovery gains).
6. **Schema teaching pass** (high / hours, description-only edits) — bash schema omits merged stderr, the 50KB cap, non-persistent cwd/exports, and the silent background-process kill (tools.py:904-914 vs the killpg finally block at 137-144); fetch schema doesn't warn that localhost/private/tailnet is blocked — on this stack the most likely first fetch is `http://localhost:8080` (tools.py:1016); read_file offset is documented 0-indexed while every number the model sees is 1-based, including grep -n output — an off-by-one on every chained navigation (tools.py:928 vs 332-335); web_search schema should reflect SEARXNG_URL truth and gain `pageno`/`time_range` (tools.py:851, 1034). Local models follow schema text far more reliably than system-prompt prose.
7. **Security quick wins** (medium-high / hours) — (a) `_guard_write_path` blocks .git/config but not .git/hooks (arbitrary code execution on next git run), nor ~/.config/systemd/user, ~/.config/autostart, ~/.local/bin (tools.py:281-298); (b) env scrub leaks OPENAI_API_KEY — the very key runner.py's `_key_endpoint_trusted` guards against exfiltration is handed to any model-authored `env` (tools.py:221-227 vs runner.py:194-212); add exact-name denylist + 'TOKEN' substring; (c) extend the existing prlimit call with RLIMIT_NPROC/FSIZE/CPU — fork bombs and disk-fill run free today (tools.py:87-115); (d) apply OPENBEAST_BASH_WRAPPER + `_scrubbed_env` in grep(), the one exec path Sandlock won't cover (tools.py:540-548).
8. **Runner context-window management** (high / day) — messages grow unboundedly; on context overflow the loop retries the *identical* oversized payload every 5s until max_iter (runner.py:292-303, 376-380), burning e.g. 160×5s of guaranteed failures. Detect the context error and evict/stub oldest tool results; proactively stub past ~70% of `--context-budget` (currently prose-only at runner.py:94-99). All SOTA loops compact.
9. **edit_file teach-on-failure + post-edit window** (high / day) — on zero-match, run a whitespace-normalized search and quote the near-match verbatim; detect pasted `N\t` line-number prefixes; recommend write_file fallback after repeated failures (tools.py:576-585). On success, echo ~5 numbered lines around the change — saves a whole read_file round-trip per edit (tools.py:603-617). Backed by SWE-Edit (arXiv:2604.26102: +12.5pp edit success on Qwen3-8B via fallback routing — exactly this model class) and SWE-agent's post-edit window finding.
10. **Plan/todo tool** (high / day, new tool) — every 2026 SOTA agent ships one (Codex `update_plan`, opencode `todowrite`, Claude Code TaskCreate/TaskList per the findings' citations); it is the standard mitigation for goal drift in long loops and acts as external memory that survives context pressure — worth more to a bounded-window 27B than to a frontier model. Pure in-process state, zero security surface, ~50 tokens/call; state on a ContextVar like `_BASE_DIR_OVERRIDE`, re-injected each turn.

## Improve existing tools (grouped by tool)

### bash / run_reaped
- **Head+tail truncation with visible marker** — see Top-10 #1. Marker must survive the 50k slice; steer the next action ("re-run with | head/grep, or narrow"). (tools.py:119-126, 157-158, 253)
- **Always surface nonzero exit codes** — one line; gives the model a machine-stable failure token. (tools.py:251-253)
- **Return partial output on timeout** — `TimeoutExpired(output=bytes(kept))`; same treatment in `_run_diagnostics`. (tools.py:130-134, 254-255)
- **Clamp model-supplied timeout** to 1-600s with an explanatory note; runner has no per-call wall-clock budget, so this is the only defense. (tools.py:230, schema :910)
- **Fix the "force EOF" fallback** — `os.close()` does not wake a blocked `read(2)` on Linux; each escaped-grandchild incident leaks a thread + 4MB buffer + pipe fd in the long-lived identity server, and fd-number reuse can cross-contaminate concurrent requests. Use non-blocking read + selectors with a deadline. (tools.py:145-151; low impact, day)
- **Instrument the killpg-in-finally path** — append "[note: background processes were killed — this tool cannot run servers]" so the silent trap becomes a taught lesson. (tools.py:137-144)
- **Schema expansion** — merged stderr, output cap, fresh-shell-per-call, background kill; mirror in `_AGENT_INSTRUCTIONS`. (tools.py:904-914, runner.py:50)

### read_file
- **Cap returned chars + clamp long lines** — see Top-10 #3.
- **Indexing coherence** — offset is 0-indexed, display is 1-indexed, grep -n is 1-based; models reliably land one line off. Prefer 1-based offset; at minimum append "next: read_file(path, offset=501)" continuation hints. Offset-past-EOF currently returns an empty *success* ("lines 801-800 of 600") — make it an error. (tools.py:332-335, :928)

### write_file
- **Report create vs clobber** — "Overwrote existing file (was 3,210 bytes, now 890)" is a strong self-correction signal; stronger option: refuse first blind overwrite of a never-read file with `overwrite=true` escape hatch. (tools.py:505-521)
- **Atomic write + pinned encoding** — tempfile + `os.replace()` preserving st_mode; `encoding='utf-8'` (POSIX-locale systemd services raise UnicodeEncodeError on Python <3.15). The symlink-safety comment at :508-510 overstates realpath()'s guarantee — use `O_NOFOLLOW` on the final component if the comment is to be true. (tools.py:516)

### edit_file
- **Teach-on-failure trio + post-edit window** — see Top-10 #9.
- **Encoding asymmetry** — bare `open(path,'r')` strict-crashes on non-UTF-8 files that read_file (errors='replace') happily shows the model; use `errors='surrogateescape'` on both sides for lossless round-trip, atomic writeback. (tools.py:567, :599 vs :324)
- **Batched multi-edit parameter** — optional `edits` array with all-or-nothing semantics and one diagnostics run at the end; each single-pair call today is a full prompt re-encode at ~140 tok/s. Backward-compatible degenerate form keeps eval suites untouched. (tools.py:556; runner.py:288-303)

### beast-assist diagnostics
- **Zig has_main fix** — see Top-10 #4. Highest urgency: it can corrupt the armed A/B.
- **Footer honesty** — the "warnings" label is derived from substring-counting 'error'; go vet failures carry no 'error' token, so hard-broken builds get labeled warnings. Use rc. Add "(+K more lines)" on the 30-line/2048-byte cut. (tools.py:490-494)
- **rustc-in-Cargo false errors** — lone-file rustc errors on every `mod x;` in a Cargo project; detect Cargo.toml and skip or `cargo check` with scratch CARGO_TARGET_DIR. (tools.py:420-426)
- **py_compile litters `__pycache__`** into the user's source tree — set PYTHONPYCACHEPREFIX. (tools.py:447)
- **Upgrade python checker to pyright batch CLI** (`--outputjson`, one-shot, NOT the deleted Tier-2 sidecar) — the plan itself calls py_compile "near-vacuous" for 47% of the suite; measure cold-start latency and no-annotation false-positive rate first, fall back to pyflakes per LANG_AWARENESS_PLAN §3.2.
- **Plan the ship path** — literature strongly predicts the on-arm wins (SWE-agent's linter-on-edit was a top ACI intervention; RLCSF arXiv:2510.22907; arXiv:2606.17514 — effects largest for weaker models, i.e. the Qwen3.8-27B class). Pre-write the default-ON flip, and stage a stricter gate mode (reject edits introducing *new* errors — needs a before/after diff to avoid punishing edits to already-broken files).

### list_files
- **Correctness**: `glob.escape(directory)` — a path containing `[`/`?`/`*` silently matches nothing (tools.py:528).
- **Ergonomics**: default ignore set (.git, node_modules, __pycache__, .venv, build, target) — the 200-cap currently fills with junk from the first alphabetical subtree; hidden files (.github/, .gitignore) are undiscoverable and undocumented; directories are dropped entirely (isfile-only), hiding structure; absolute-path spam wastes ~8KB of a budgeted context — header once, relative paths after. Consider `rg --files`/fd backend (one binary shared with the grep swap). (tools.py:524-537, schema :954-969)

### grep
All items in Top-10 #2. Additional: on overflow, return first ~100 matches + per-file tally ("src/foo.py: 312 matches") + narrowing instruction, per SWE-agent's 50-result-cap discipline and Anthropic's tool-writing guidance.

### fetch
- **Preserve links** — the tag-strip deletes every `<a href>`, making any fetched index page a navigational dead end; rewrite to `[label](url)` with urljoin, bounded ~200 links. (tools.py:821)
- **Truncation honesty + continuation** — the note fires only on cleaned-text length, not wire-read cap; add a `save_to` param writing full cleaned text into the workspace so read_file/grep can page it (composes with existing offsets; matters for RBAC guests who lack bash+curl). (tools.py:794, 814, 827-828)
- **Readability/markdown extraction** — trafilatura/readability-lxml (local pip, no cloud) cuts fetched-page tokens 3-5x while preserving code fences; keep the regex path as fallback and the pinned SSRF opener untouched — it's ahead of most OSS agents. (tools.py:824-831)
- **Happy-eyeballs over vetted IPs** — only `ips[0]` is dialed; AAAA-first hosts on a broken-v6 rig (NordVPN munges routes per known collision) fail wholesale despite a good vetted A record. Loop over the full vetted list; security unchanged. (tools.py:717-722, 749)

### web_search
- **HTTPError ≠ "not running"** — HTTPError subclasses URLError, so a 403 (json format disabled) yields "SearXNG is not running. Start it with: docker run..." — advice that can never work and that a 27B will loop on; catch HTTPError first, catch JSONDecodeError with "json format likely disabled", and point at the stack's compose start path, not raw docker. (tools.py:858-867)

### runner.py loop
- Malformed-JSON and unknown-tool errors — Top-10 #5.
- Context management — Top-10 #8.
- **task_done `status` enum** [\"success\",\"partial\",\"blocked\"] + optional `blockers` — today a stuck agent's only honest exit is burning 200 iterations, or lying (poisoning eval SOLVE rates). Also fix the mid-batch return leaving dangling tool_call_ids that `_rebuild_messages_from_log` replays asymmetrically on --resume. (tools.py:886-888, 1046-1062; runner.py:383-396)
- **Codify the tool-suite contract** — a docstring on `_TOOL_REGISTRY`: flat schemas, ~10 tools, every new tool must show a v5-suite eval win. The design is now measurably validated for this model class ("The Devil Is in the Interface", arXiv:2608.11386: atomic tools up to 4.7x pass^k on Qwen3Coder-30B; JSONSchemaBench: constrained decoding covers only 3-41% of complex schemas).

### mcp_server.py
- **Unify MCP-transport RBAC with the identity server** — MCP HTTP today has per-PROCESS RBAC (OPENBEAST_MCP_TOOLS env allowlist, mcp_server.py:68-86) vs the OpenAPI server's per-identity JWT profiles; the 2026-07-28 stateless spec (identity in `_meta`, .well-known discovery, cacheable lists) makes per-request allowlist resolution natural. (medium/days)

## Security notes

1. **OPENAI_API_KEY scrub gap** — the scrub (tools.py:221-227) and runner (runner.py:194-212) disagree about what a stack secret is; runner builds endpoint-trust gating for this exact key while bash hands it to any model command. Add an exact-name denylist of keys the stack's own code reads + 'TOKEN' substring. (hours)
2. **Executable-persistence write paths** — .git/hooks/* is arbitrary code execution on next git invocation, strictly worse than the .git/config vector already blocked; same class: ~/.config/systemd/user, ~/.config/autostart, ~/.local/bin. Reachable through write_file even where RBAC withholds bash. Denylist stays defense-in-depth; Sandlock remains the real boundary. (tools.py:281-298; hours)
3. **Resource caps beyond RLIMIT_AS** — fork bombs saturate the PID table (killpg can itself fail under PID exhaustion) and `dd` fills the disk with zero memory pressure; extend the existing prlimit loop with NPROC/FSIZE/CPU and consider a bash-concurrency BoundedSemaphore mirroring `_DIAG_SLOTS` (N users × 32GB still OOMs the rig). (tools.py:87-115; hours)
4. **grep escapes the sandbox wrapper** — bash and diagnostics honor OPENBEAST_BASH_WRAPPER; grep doesn't, so when Sandlock ships, model-supplied patterns can read anything the uid can (e.g. ~/.ssh — writes are guarded, reads deliberately aren't; the sandbox is exactly the layer meant to decide that). Extract `_maybe_wrap()`, apply with `_scrubbed_env()`. (tools.py:242-244, 473-475 vs 540-548; hours)
5. **Proxy env vars vs the pinned opener** — build_opener auto-installs ProxyHandler; with a proxy set, the SSRF guard vets the origin while the socket construction targets the proxy — currently fails closed *by accident*. Make proxy-blindness explicit: `ProxyHandler({})` + comment. (tools.py:777-778; hours)
6. **LSP servers execute code** — rust-analyzer builds and runs build.rs/proc-macros from the workspace it indexes (a model-written Cargo project = code execution the moment it's indexed); gopls can trigger network downloads. Any LSP wiring must inherit the full diagnostics hardening contract (scrubbed env, go env quartet GOTOOLCHAIN=local/GOPROXY=off/GOFLAGS=-mod=readonly/CGO_ENABLED=0, buildScripts/procMacro disabled, wrapper parity, rlimits) — write it into the plan *now*, while integration is hypothetical. (tools.py:430-434, LANG_AWARENESS_PLAN §3.3/§4; hours)
7. **MCP tool descriptions are supply chain** — the moment the runner consumes third-party MCP, descriptions are untrusted input injected into every prompt. OWASP MCP Top 10 lists tool poisoning at #3; MCPTox (arXiv:2508.14925) found ~5.5% of 1,899 real servers poisoned; Unicode TAG-block attacks (arXiv:2607.05744) hide what the model sees from the human approver. Plan: pinned registry with sha256 of the serialized tool list verified at mount, fail-closed on drift (same pattern as the stack's weight sha256 pinning); strip TAG-block/control codepoints; audit-log tool-list changes; never auto-mount from registries. (day)
8. **Diagnostics literature note** — beast-assist's push design is the evidence-backed shape (SWE-agent, RLCSF); the security posture (default-OFF pending A/B, scrubbed env, wrapper) is correct and should be preserved through any default-ON flip.

## Explicitly rejected (does NOT fit the local-first / security ethos)

- **Embedding/semantic code search** — measured evidence says grep wins at this repo scale (Augment: embeddings didn't help their SWE-bench agent; Cursor's ~12.5% gains concentrate in large monorepos), and a resident embedding index competes for the one 5090's VRAM against the "fill hardware with the LARGEST model" ethos. Park as measured-and-rejected in docs/TODO.md; revisit only if beast-gate serves multi-million-line customer repos or evals still show orientation failures after repo-map.
- **Cognitive-scaffolding tools (scratchpad, hypothesis tracker)** — "The Devil Is in the Interface" tested them controlled and found no benefit; every added schema dilutes 27B tool selection.
- **Cloning Codex's apply_patch grammar verbatim** — OpenAI states it works because GPT was *trained* on that exact format; aider's cross-model data is why open models get search/replace blocks. Ship the list-of-hunks form; eval-gate any richer diff.
- **Persistent REPL for python_exec** — breaks the identity server's per-request shard model and RBAC audit story; stateless per call only.
- **Auto-mounting MCP servers from public registries** — 70k+ heavily untrusted third-party listings vs 9.6k official; violates the pinned, fail-closed supply-chain posture.
- **Proxy support in fetch** — a proxy bypasses IP vetting entirely; fetch stays deliberately proxy-blind (consistent with resolve-then-pin).
- **Warm LSP sidecar for the eval harness** — already deleted with sound measured reasons (single-file fixtures have nothing cross-file; zls is ast-check-grade; editor latency budgets don't apply) — LANG_AWARENESS_PLAN §4 stands; LSP value lives only on the free-agent/multi-file surface.
- **Unrestricted Playwright browser for all profiles** — a scriptable browser is an exfiltration primitive under page prompt-injection; acceptable only admin-only behind a token-capped facade (listed above as deferred, not general-purpose).
